Harbor Grill (demo page)

Open the chat bubble at the bottom right. This page must be served from http://localhost:8080 (the origin npm run db:seed allows for the demo restaurant).

  1. Start MongoDB, npm run db:migrate && npm run db:seed, and copy the printed rest_001 widget key.
  2. Start the API with OPENAI_API_KEY set: npm run dev.
  3. Replace PASTE_WIDGET_KEY_HERE below, then run python3 -m http.server 8080 in the repository root and open http://localhost:8080/examples/widget-test.html.

Things to try: "How much is the grilled salmon?", "Are you open tomorrow?", "Is the salmon safe for a peanut allergy?" (must give the restaurant's phone number), "Can I talk to a person?" or "What's your phone number?" (must give the restaurant's phone number).
